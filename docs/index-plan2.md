# Use Numeric Story Numbers on Index Cards

## Summary

Each merged tab will use a letter and its existing story range (`A 1-50`, `B 51-100`,
`C 1-55`, etc.). Each story’s index-card link will display only its existing
story number, such as:

`64`

No level name, “Starters,” or other prefix will be added.

## Changes

- Rename merged tab labels to letters and ranges:
  - `A 1-50`, `B 51-100`, `C 1-55`, etc.
- Add the existing story number only to each story link/card, left of the title, on
  the level index pages.
- Preserve the existing story title and story-page content unchanged.
- Do not add story numbers to story-page headings, story text, MENU links, or other
story content.
- Keep existing story numbers.
- Keep the six-level grouping and main-index ownership already defined.
- Update the level-grouping documentation to match the six main indexes and their
  merged collections.

## Verification

- Confirm each index card displays only a number like `64` beside the
  unchanged story title.
- Confirm tabs display only letters and ranges, such as `A 1-50`, `B 51-100`,
  `C 1-55`, etc.
- Confirm story titles remain unchanged.
- Confirm story pages remain unchanged and display no locator.
- Confirm every story number remains unique within its tab.
- Verify all existing tab links and MENU links still work.
